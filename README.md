# TokoKu - Kasir & Landing Page

Struktur file:

- `index.html` : struktur halaman (landing page + aplikasi kasir)
- `style.css`  : tampilan, termasuk mode terang/gelap dan responsif HP
- `script.js`  : logika kasir (keranjang, diskon, PPN, kembalian, riwayat, laporan, produk)

Cara memakai: simpan ketiga file dalam satu folder yang sama, lalu buka `index.html` di browser.
Data transaksi dan produk disimpan di localStorage browser.
